MDViewer opens Markdown files in a Paseo tab and draws them like a document: GitHub-flavored Markdown, syntax highlighting, KaTeX math and Mermaid diagrams, in Paseo's light or dark theme. The same tab switches to Split or Source mode to edit the file, and edits save on their own.

Files open from Markdown links in replies, the Files tree, search, or `/mdv path/to/file.md`. After a turn, buttons list up to 12 Markdown files created or changed during that turn, and each one opens in its own tab. Mentioning an unchanged file adds no button. The first time you open a `.md` file, Paseo asks which viewer to use; choose MDViewer and tick Don't ask again. Requires Paseo 0.15.4 or later on the app and daemon. It was tested on the macOS desktop app.

Inside a tab you can show an outline, find text, change the reading width and text size, open a diagram or image full screen and pinch to zoom, tick task-list checkboxes, and copy code blocks. Clicking the file path copies the path, file name or folder, or reveals the file in Finder. The interface is in English and Korean.

Settings: changed-document buttons (on), an agent card tool that lets Claude and Codex post a document card (off), the starting mode, reading width, text size, and automatic saving.

A Markdown file can contain HTML, so every document is treated as untrusted. The preview runs in a sandboxed frame, its HTML is sanitized, and a content security policy blocks scripts and network requests other than loading https images.

The plugin reads Markdown files and the images they reference on the daemon machine, writes the Markdown files you edit, scans paths and metadata under the agent's working directory for turn changes, and runs the system file opener when you ask to reveal or open a file. The turn scan reads neither document contents nor conversation text. It can also include changes by another program in that directory; a missing start snapshot or a scan limit can leave files out. It makes no network requests of its own; a document that embeds remote images loads them over https when opened. Full-screen diagrams, find and the outline need the desktop or web app; other clients use Paseo's own Markdown renderer. With Better Paseo's "Plugin markdown for replies" turned on, reply links open with the operating system instead.
