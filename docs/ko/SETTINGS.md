# 설정

설정 화면은 Paseo 설정 → Plugins → MDViewer의 톱니바퀴나 Command Center의 "MDViewer 설정"에서 연다. 값은 데몬에 저장되어 연결된 모든 기기가 같이 쓴다. 지금 들어 있는 설정은 6개이고, 나머지는 후보다.

English: [docs/SETTINGS.md](../SETTINGS.md)

## 현재 설정

| 키 | 화면 이름 | 기본값 | 동작 |
|---|---|---|---|
| `turnButtons` | 턴 뒤에 변경된 문서 표시 | 켬 | 이번 턴에 생성·변경된 Markdown 파일의 버튼 행을 붙인다 |
| `agentTool` | 에이전트 카드 도구 | 끔 | 에이전트에 `show_markdown` 도구를 붙인다. 바꾼 뒤 새로 여는 세션부터 적용된다 |
| `defaultMode` | 문서를 여는 모드 | 보기 | 새로 여는 문서의 시작 모드(보기, 분할, 원문) |
| `width` | 본문 폭 | 보통 | 좁게 700px, 보통 860px, 전체 폭 |
| `fontScale` | 글자 크기 | 100% | 새로 여는 문서의 글자 크기. 탭에서 핀치나 A-/A+로 따로 바꿀 수 있다 |
| `autosave` | 자동 저장 | 켬 | 끄면 툴바의 저장 버튼으로만 저장한다 |

스키마 정본은 `shared/settings.ts`다. 시작 모드와 글자 크기는 새 탭에만 적용되고, 이미 연 탭은 탭마다 저장된 값을 쓴다.
